# Gen Z Studio — অ্যাপ (PWA) ফোল্ডার

এই ফোল্ডারটা কোনো HTTPS ওয়েব ঠিকানায় রাখলে Chrome থেকে **Install** করা যায় — মোবাইলে হোম স্ক্রিনে, কম্পিউটারে ডেস্কটপে আইকন আসে, অফলাইনেও চলে।

## GitHub Pages-এ তোলা (ফ্রি)
1. GitHub-এ `genztheology` অ্যাকাউন্টে নতুন রিপো: **studio** (Public)।
2. এই ফোল্ডারের সব ফাইল (index.html, manifest.webmanifest, sw.js, আইকনগুলো, .nojekyll) রিপোর মূল জায়গায় আপলোড।
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save।
4. ১–২ মিনিট পরে লিংক: `https://genztheology.github.io/studio/`

## হালনাগাদ
নতুন সংস্করণ এলে শুধু ফাইলগুলো বদলে দিন। যাঁরা ইনস্টল করেছেন, তাঁরা পরের বার খুললে "🔄 নতুন সংস্করণ এসেছে — চালু করো" দেখবেন।

## মনে রাখুন
- সব কাজ ব্যবহারকারীর নিজের ডিভাইসে হয় — কোনো ফাইল সার্ভারে যায় না।
- এই ফোল্ডারে কোনো গোপন তথ্য নেই; পাবলিক রিপোতে রাখা নিরাপদ।
- `Gen Z Studio.html` (একক ফাইল) আলাদাভাবে কম্পিউটারে রেখে ইন্টারনেট ছাড়াও খোলা যায়।
